# 인사말 = Ungkapan Salam

1. 안녕하세요 / 안녕하십니까 : Selamat pagi/siang/sore/malam
2. 만나서 반갑습니다 : Senang bertemu anda
3. 처음 뵙겠습니다 : Senang bertemu dengan anda (pertama bertemu)
4. 네, 반갑습니다 : Ya, senang bertemu dengan anda
5. 어떻게 지냈습니까 / 어떻게 지내세요 : Bagaimana kabarnya
6. 잘지냅니다 / 잘지냈어요 : Baik-baik saja
7. 안녕히계십시요 / 안녕히계세요 : Selamat tinggal
8. 안녕히가십시요 / 안녕히가세요 : Selamat jalan
9. 또 만나요 : Sampai jumpa lagi
10. 안녕히주무세요 / 잘자요 : Selamat tidur
11. 생일 축하합니다 / 생일 축하해요 : Selamat ulang tahun
12. 새해복 많이 받으세요 : Selamat tahun baru
13. 결혼축하합니다 / 결혼축하해요 : Selamat menikah
14. 축하합니다 / 축하해요 : Selamat
15. 많이 잡수세요 / 많이 식사하세요 : Selamat makan
16. 잘 먹겠습니다 : Makan dengan baik
17. 잘 먹었습니다 / 잘 먹었어요 : Terimakasih atas hidangannya
18. 실예합니다 / 실예지만 : Permisi
19. 네, 하세요 : Ya, silakan
20. 죄송합니다 / 미안합니다 / 미안해요 : Minta maaf
21. 괜찮습니다 / 괜찮아요 : Tidak apa-apa
22. 어서 오십시요 / 어서 오세요 : Selamat datang
23. 들어 오십시요 / 들어 오세요 : Silakan masuk
24. 감사합니다 / 고맙습니다 / 고마워요 : Terimakasih
25. 천만에요 : Terimakasih kembali
26. 늦어서, 죄송합니다 : Maaf saya terlambat
27. 도와주섰어, 갑사합니다 : Terimakasih atas bantuannya
28. 어떻게 오셨어요 : Apa yang bisa saya bantu?
29. 와주셨어, 고맙습니다 : Terimakasih atas kedatangannya  
...
30. 앉으세요 : Silakan duduk (안따)
31. 일었어세요 : Silakan berdiri
32. 기도합시다 : Mari berdoa
33. 끝났어요 : Selesai
34. 와장시레 가다 / 오다 : Izin ke toilet
35. 도와주세요 : Tolong dibantu
36. 잘부탁 드립니다 : Mohon bantuannya
37. 수고하세요 : Selamat bekerja
38. 수고핬었어요 / 수고핬었습니다 : Selamat atas terselesaikannya pekerjaan anda
39. 열심히해요 : Bekerja giat/sungguh-sungguh
40. 오래 만내요 : Lama tidak bertemu
41. 잘되내요 : Selamat bersenang-senang
42. 여기 있어요 : Silakan terima
43. 여보세요 : Halo (dalam telepon)
44. 잔깜만 기다리세요 : Silakan menunggu
45. 앞으로 잘부탁드립니다 : Kedepan mohon bantuannya
46. 많이 드세요 : Makan yang banyak
47. 별말씀을요 : Terimakasih kembali
48. 일하세요 : Silakan bekerja
49. 사과합니다 / 사과해요 : Minta maaf
50. 다녀오겠습니다 : Akan datang rutin
51. 네, 잘 다녀오세요 : Ya, datanglah dengan baik
52. 힘내세요 : Semangatlah
53. 행복하세요 : Berbahagialah 
54. 환영합니다 : Selamat datang
55. 내일 봅시다 : Sampai jumpa besok
56. 이따봐 : Coba sebentar (informal)
