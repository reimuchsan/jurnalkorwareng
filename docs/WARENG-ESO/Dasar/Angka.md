# Angka
## Sino Korea 
Untuk uang, tanggal (hari, bulan, tahun), menit, nomor berurutan. 

- 일 : 1
- 이 : 2
- 삼 : 3
- 사 : 4
- 오 : 5
- 육 : 6
- 칠 : 7
- 팔 : 8
- 구 : 9
- 공 : 0
- 십 : 10
- 백 : 100
- 천 : 1000
- 만 : 10000
- 억 : 100000000
