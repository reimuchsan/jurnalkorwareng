# Tata Bahasa

Da hilang, ex: 먹다 - > 막습니다  
Predikat selalu diakhir.  
Objek sebaiknya didepan predikat.

## Sedang

마시다 - > 마시**고 있**습니다  
공부하다 - > 공부하**고 있**습니다 

### Contoh
1. Saya sedang menabung uang 
2. Saya ingin belajar bahasa Korea 
3. Saya ingin minum kopi
4. Mina ingin bertemu Sujan
5. Minsu sedang rapat 
6. Supika ingin membeli 2 ekor babi

. 

1. 저는 돈을 여금하**고 있**습니다 
2. 저는 한국어를 공부하**고 있**습니다 
3. 저는 커피를 마시**고 있**습니다 
4. 미나가 수잔을 만나**고 싶**습니가
5. 민수가 회의를 하**고 있**습니다 
6. 수피카가/수삐까가 두마리 되지를 사**고 싶**습니다

## Kalimat Negatif

- **안** : Tidak
- **못** : Tidak (bisa)  
먹습니다 - > **안** 먹습니다  
마십니다 - > **안** 마십니다  
공부합니다 - > 공부**안**합니다
- **지않**다 - > **지않**습니다 : Tidak  
먹다 - > 먹**지않**습니다  
공부하**지않**습니다
### Contoh 
1. Saya tidak minum kopi
2. Sujan tidak makan daging babi 
3. Supika tidak belajar bahasa Thailand 
4. Minsu tidak membeli radio
5. Saya tidak pergi

. 

1. 저는 커피를 **안**마십니다
2. 수잔이 되지고기를 **안**먹습니다
3. 수피카가 태국어를 공부**안합**니다
4. 민수가 라디오를 사**지않**습니다
5. 저는 가**지않**습니다

## 에 / 에서

| **에**                           | **에서**   |
| ------------------------------- | -------- |
| Di, ke, pada, pukul, per, dalam | Di, dari |

- **에** : di - > biasanya dipakai 있다 / 없다 / 많다 ... 
	- 교실**에** 학생이 많습니다
	- 동생이 방**에** 있습니다
- **에서** : di - > kata kerja / kegiatan
	- 학생이 교실**에서** 공부합니다
- **에** : ke - > 가다 / 오다 / 다니다 / 보내다
	- 저는 한국**에** 갑니다
	- 미다씨가 시장**에** 사과를 보냅니다
- **에** : pada - > keterangan waktu
	- 일요일**에** 저는 학교에 갑니다
	- 낫**에** 너무 덥습니다
- **에** : pukul - > jam
	- 07:00 시**에** 저는 학교에 갑니다
- **에** : per - > jumlah / satuan 
	- 사과가 한개**에** 만원 입니다
- **에** : dalam - > jumlah waktu
	- 하루**에** 저는 커피를 3잔 마십니다
- **에서** : di (mewakilkan)/dari - > biasanya ada 까지 (sampai), 걸리다 (memakan/membutuhkan waktu)
	- 집**에서** 학교까지 30분쯤 **걸립니다**
### Contoh
1. Di pasar ada banyak orang
2. Andi berenang di danau
3. Dalam sehari saya makan 3 kali
4. Ibu ingin pergi ke pasar
5. Satu ekor ayam 5000 won
6. Saya berangkat ke sekolah pukul 9.30
7. Dari Jogja sampai Wonosari membutuhkan waktu sekitar 2 jam
8. Pada hari minggu saya tidak di rumah

.

1. 시장**에** 사람이 많이있습니다
2. 안디가 호수**에서** 수영합습니다
3. 하루**에** 저는 세번 먹습니다
4. 어머니가 시장**에** 가 고 십습니다
5. 닭이 한마리**에** 오천원 입니다
6. 저는 학교**에** 아홉시반**에** 출발합니다
7. 조그자**에서** 워너사리**까지** 두시간쯤 걸립니다
8. 일요일**에** 저는 집에서 잡니다

## Bentuk Informal
Tidak peduli bacim, kata kerja yang diubah

| 아요                 | 어요         | 해요                  |
| ------------------ | ---------- | ------------------- |
| Vokalnya akhir 아/오 | Selain 아/오 | Yg akhirannya ada 하 |

- **아요**
	- 가다 -> 가아요 -> **가요**
	- 오다 -> 오아요 -> **와요**
	- 가라타다 -> **가라타요**
	- 알다 -> **알아요**
- **어요**
	- 먹다 -> **먹어요**
	- 마시다 -> 마시어요 -> **마셔요**
	- 배우다 -> 배우어요 -> **배워요**
	- 씻다 -> **씻어요**
- **해요**
	- 공부하다 -> **공부해요**
	- 수영하다 -> **수영해요**
	- 하다 -> **해요**

!!! Note

    Vokal gabungan 에, 예, 애, 얘 langsung masukkan 요

3. 수피카씨가 과일를 먹**을겁니다**
4. 수잔씨가 강에서 수영**할겁니다**

## Dibanding/Daripada ... Lebih

| **보다 / 비해** | **...** | **더** |
| ----------- | ------- | ----- |
| Dibanding   |         | Lebih |
| Daripada    |         |       |
- 한국은 인도네시아**보다 더** 작습니다
- 인도네시아**보다** 한국은 **더** 작습니다

### Contoh
1. Dibanding apel anggur lebih mahal
2. Dibanding Korea Indonesia lebih besar
3. Mobil lebih cepat dibanding sepeda
4. Bahasa Thailand lebih sulit dibanding bahasa Jepang

.

1. 사과**보다** 포도는 **더** 비쌉니다
2. 한국**보다** 인도네시아는 **더** 큽니다
3. 자동차는 자전거**보다 더** 빠릅니다
4. 태국어는 일본어**보다 더** 머렵습니다

## Harus

**아 / 어 / 해** + 야하다 -> **야해요**

- 가다 -> 가요 -> 가**야해요**
- 먹다 -> 먹어요 -> 먹**어야해요**
- 마시다 -> 마셔요 -> 마**셔야해요**
- 수영하다 -> 수영해요 -> 수영**해야해요**

### Contoh
1. Dalam sehari saya harus mandi 2 kali
2. Mina harus menyeberang jalan
3. Saya setiap hari harus belajar bahasa Korea

.

1. 하루에 저는 도번 샤워**해야해요**
2. 미나씨가 길을 건어가**야해요**
3. 저는 매일 한국어를 공부**해야해요**

## Sudah (bentuk lampau)

**았어요 / 었어요 / 앴어요**

- 가다 -> 가 -> **갔어요**
- 마시다 -> 마시 -> 마**셨어요**
- 먹다 -> 먹 -> 먹**었어요**
- 공부하다 -> 공부하 -> 공부**했어요**

### Contoh
1. Saya sudah membaca buku
2. Mina sudah melihat Sujan
3. Minggu lalu saya pergi ke pasar

.

1. 저는 책을 읽**었어요**
2. 미나씨가 수잔을 **봤어요**
3. 지난 주에 저는 시장에 **갔어요**

## Karena/lalu (sebab akibat)
**아 / 어 / 해** + **서**

- 가다 -> 가 -> **가서**
- 먹다 -> 먹 -> 먹**어서**
- 마시가 -> 마시 -> 마**셔서**
- 공부하다 -> 공부하 -> 공부**해서**

### Contoh
1. Saya karena sakit minum obat
2. Karena ingin pergi ke Korea saya harus belajar bahasa Korea
3. Karena macet saya terlambat

.

1. 저는 약을 아파요->**아파서** 먹습니다 
2. 저는 한국에 가 고 싶**어서** 한국어를 공부해야합니다
3. 저는 막**혀서** 늦어요/늦습니다
