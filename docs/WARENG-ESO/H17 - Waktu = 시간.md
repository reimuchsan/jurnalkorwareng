10. 다음주 : Minggu depan
11. 지난주 : Minggu lalu
12. 이번달 : Bulan ini
13. 다음달 : Bulan depan

17. 작년 / 지난년 : Tahun lalu

20. 매달 : Setiap bulan

---
## Pembagian Waktu

1. Berdasarkan AM/PM
	- AM : 오전
	- PM : 오후
2. Berdasarkan jam makan
	- Waktu makan pagi : 아침 식사
	- Waktu makan siang : 점심 식사
	- Waktu makan malam : 저녁 식사
3. Berdasarkan waktu kerja 
	- Kerja pagi : 주간
	- Kerja malam : 야간
	- Kerja lembur : 야근
4. Berdasarkan terbit terbenam matahari 
	- Siang : 낫
	- Malam : 밤
	- Subuh : 세벽
